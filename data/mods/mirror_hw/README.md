# Home Systems Mirrored

Gives every player the same home system, while the rest of the galaxy is generated normally. For fairer starts without changing the map.

## Rules

Changes only how home systems are generated; combine it with any rule set.

## What it changes

- After the galaxy is generated, one player's home system is chosen at random.
- Every other home system loses its other planets and gets copies of that system's planets in the same orbits.
- Each player's own home planet moves to the same orbit as in the chosen system; home planets themselves are not changed.
- The rest of the galaxy is left as generated.

## Keys

No changes: every key works as it does without packages.

## Needs and conflicts

Required by Improved Multiplayer. Can't be combined with Full Mirror, Full Mirror except home systems or VDC-GM3: only one package may generate the galaxy. Uses a script: in multiplayer the host generates the galaxy, every player needs the same package set, and the script must match on all machines.

## Saves

Saves record this package and need it enabled to load.
