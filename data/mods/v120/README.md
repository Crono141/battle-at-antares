# Version 1.2 mod

Brings the game as close as the settings allow to the older 1.2 patch, for players who prefer the rules before 1.3. It is not needed to load 1.2 saved games.

## Rules

Version 1.2 rules instead of 1.31. Changes listed here are relative to 1.31.

## What it changes

Races and setup:
- Creative costs 6 picks instead of 8.
- The Psilons get their 1.2 design back: an Artifacts home world instead of a Large home world (two of its Hard and Impossible AI variants add a Large home world).
- Home systems may have just one planet (without packages the game guarantees at least three).
- Loknar brings no technologies when he joins, as in 1.1 and 1.2.
- The AI's production penalty on Tutor is halved.

Combat:
- Ship initiative is off, whatever the in-game option says.
- Ion Pulse Cannon, Plasma Cannon and Gyro Destabilizer have their 1.2 size, cost and damage.
- The Damper Field no longer protects marines from Neutron Blasters and Death Rays.
- Planetary defenses can use a different set of weapon modifications.
- The Star Base can't mount a Warp Dissipator; its special-system slots are those of 1.2.
- The Guardian has no Spatial Compressors.
- Antaran ships lose the jammers, frigate bombs, extra Spatial Compressor and other additions of 1.3; Antaran raiding fleets can include up to 6 raiders.
- One AI ship-design table returns to its 1.2 values.

Galaxy map:
- Stealth Field, Cloaking Device and Phasing Cloak no longer hide ships on the galaxy map (that only started working in later fan patches).

Help:
- The English help file is the 1.2 one, original mistakes included.

## Keys

| Key | Screen | What changes |
|---|---|---|
| H | Tactical combat | Not available: ship initiative is always off (the in-game Ship Initiative option can't switch it on), so there is no wait with all ships. |
| W | Tactical combat | Works as in the classic game, without initiative. |
| Alt+A, Alt+D | Build | Auto Design still redesigns every ship, but follows the Version 1.2 AI design rules, so the designs differ. |

## Needs and conflicts

Conflicts with Improved (v150i), Melee and ICE.

## Saves

Saves record this package and need it enabled to load.
