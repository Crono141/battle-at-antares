# Random Technology Tree

Shuffles the technology tree at the start of every new game, so familiar research paths no longer work. For experienced players who want a fresh tree each game.

## Rules

Changes no other rules. It can be combined with rule packages and rearranges the technology tree they produce.

## What it changes

- At the start of a new game, research fields are shuffled between the eight research categories, roughly keeping their cost order.
- Technologies are redealt among those fields: cheaper technologies tend to land in cheaper fields, and a field may offer fewer choices than usual.
- The starting fields Engineering, Chemistry, Nuclear Fission, Physics and Electronics keep their usual technologies.
- The hyper-advanced fields stay at the end of each category, and the four advanced governments stay together in one field.
- All players share the same shuffled tree. It is decided once, when the game is created.

## Keys

No changes: every key works as it does without packages.

## Needs and conflicts

No dependencies or conflicts. Uses a script: in multiplayer every player needs the same package set, and the script must match on all machines.

## Saves

Saves record this package and need it enabled to load.
