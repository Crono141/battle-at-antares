# Hidden Tech Tree

Hides future research from the research screen, so you only see the choices you can research next. For players who want to discover the technology tree as they go.

## Rules

Changes no game rules on its own; combine it with any rule set (1.31 without packages, Basic, Improved and so on).

## What it changes

- The research category buttons can no longer be used to browse technology fields beyond your next research choice.
- This is the 1.50 option that blocked peeking at future technologies.

## Needs and conflicts

No dependencies or conflicts. In multiplayer every player needs the same package set.

## Saves

Saves record this package and need it enabled to load.
