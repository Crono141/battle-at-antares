# Full Mirror

Builds a galaxy in which every player gets an identical copy of the same neighbourhood, home system included. For fair multiplayer and competitive games.

## Rules

Changes only how the galaxy is generated; combine it with any rule set.

## What it changes

- The galaxy is split into equal sectors: 2 side by side for two players, 2 by 2 for up to four, 3 by 2 for up to six and 4 by 2 for seven or eight.
- One player's surroundings, the one that best fits a sector, become the template: the home system and the nearest stars that fit in a sector.
- Every other player's sector gets a mirrored copy of the template, with the same stars, planets, specials, wormholes and guarding monsters.
- Every home system has the same star colour and the same planets in the same orbits.
- Stars outside the template are removed, so the galaxy may end up with fewer stars than the size you chose.
- A marooned hero in the template is copied as a different hero in each copy.
- Nebulas are moved to symmetric positions.

## Needs and conflicts

Can't be combined with Full Mirror except home systems, Home Systems Mirrored, Improved Multiplayer or VDC-GM3: only one package may generate the galaxy. Uses a script: in multiplayer the host generates the galaxy, every player needs the same package set, and the script must match on all machines.

## Saves

Saves record this package and need it enabled to load.
