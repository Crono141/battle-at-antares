AntaresSymbols.ttf: a subset of DejaVu Sans 2.37 (Latin-1, punctuation, arrows, math, technical,
box drawing, shapes, symbols, dingbats), the fallback for every theme font so the interface's
symbols (sort arrows, bullets, markers) draw on systems without them (Wine, owner 2026-11-25).
Made with: pyftsubset DejaVuSans.ttf --unicodes=U+00A0-00FF,U+2000-206F,U+2190-21FF,U+2200-22FF,
U+2300-23FF,U+2500-25FF,U+2600-26FF,U+2700-27BF --layout-features= --no-hinting --name-IDs=*
