# Antares UI: Chrome

A theme for Antares UI (the Godot build's native galaxy): the original screens' metal at a small
size. Buttons are the Planets screen's metal button, closed all round, their lettering amber when
they are on; the figures on the top bar sit in the Fleets screen's name slot; panes are the
tech-pattern panel in the colony screen's riveted frame, which also runs round the whole view,
with pockets for the top bar and the fleet and colony buttons.

It styles the Godot build's own interface, Antares UI (ticking this turns the legacy interface off). With this and another theme enabled,
Options > Theme switches between them while you play; the first one enabled is the default.

The metal is cut from your own copy of the game (the Battle at Antares HD art), so the package
carries it in `art/` but its source code doesn't. The lettering is Russo One and Saira Semi
Condensed, under the SIL Open Font License (`fonts/OFL-*.txt`).

## Keys

None of its own.

## Needs and conflicts

None: it styles Antares UI or any interface that uses the theme names. No conflicts: several themes can be enabled at once.

## Saves

Saves don't record this package: it changes only how the game is shown.
